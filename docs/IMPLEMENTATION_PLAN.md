# خطة التنفيذ والموارد | 180-Day Pilot Plan

## 1. المدة ونقطة بدء الاحتساب
المدة المقترحة **180 يوماً** لتجهيز وإطلاق تجربة تشغيلية وإثبات دورة تصدير قابلة للتكرار. يبدأ احتسابها بعد تحقق الشروط مجتمعة:
- موافقة مكتوبة على نطاق التجربة والجهة المشرفة.
- اعتماد المسار القانوني والتعاقدي.
- توقيع عقد التنفيذ وتأمين دفعة بدء التشغيل.
- جاهزية شركة التصدير المرخصة والبنك والشركاء الأساسيين.
- تحديد المصانع والقطاعات الأولى.

أي تأخير جوهري في هذه الشروط يستلزم إعادة ضبط الجدول؛ ولا تحتسب مدة انتظار الموافقات فترة تنفيذ فعلية.

## 2. المراحل
| الفترة | الأعمال الرئيسية | بوابة القرار |
|---|---|---|
| الأيام 1–30 | التأسيس التنظيمي، توزيع الأدوار، العقود، اختيار البنك والمصدر المرخص والمصانع والقطاعات | اعتماد إطار التشغيل والشركاء |
| الأيام 31–60 | استكمال المنصة، إعداد البيانات، اختبار التسجيل والإسناد والحسابات، تدريب الفريق | قبول اختبار الجاهزية |
| الأيام 61–90 | إطلاق محدود، تسجيل المشاركين، رصد المشترين والطلبات، تأهيل الفرص | إثبات تدفق فرص مؤهلة |
| الأيام 91–120 | التفاوض والعقود وتنفيذ أول الشحنات والتحصيل والتسوية | إثبات دورة تصدير موثقة |
| الأيام 121–180 | توسيع التجربة، تحسين التحويل، قياس الأثر، تقرير التقييم وخطة التوسع | قرار استمرار/تعديل/توسع |

## 3. فريق الأساس
يبدأ التشغيل بفريق تخطيطي من **18 وظيفة** موضحة في [النموذج المالي](FINANCIAL_MODEL.md). لا يفترض تعيين الجميع في اليوم الأول؛ يمكن التدرج وفق بوابات التنفيذ، مع عدم تكليف غير المؤهلين بأعمال امتثال أو مالية منظمة. التوسع يكون وفق حجم الطلبات والصفقات وعبء العمل، لا عدد الحسابات وحده.

## 4. مؤشرات التجربة المقترحة
الأرقام أهداف أولية للنقاش وليست تعهدات نهائية قبل اختيار القطاعات والشركاء والتحقق من القدرة التشغيلية:

| المؤشر | نطاق مستهدف خلال 180 يوماً |
|---|---:|
| المصانع المشاركة | 50–100 |
| المسوقون المسجلون | 5,000–10,000 |
| المسوقون النشطون فعلياً | 500–1,000 |
| الأسواق المستهدفة | 5–10 |
| المشترون الدوليون المؤهلون | 100–200 |
| طلبات الشراء المؤهلة | 30–50 |
| الصفقات التصديرية | 10–20 |
| الشحنات المنفذة | 5–10 |

يجب تعريف المشتري والطلب والمسوق النشط والصفقة والشحنة قبل القياس وربط كل رقم بمصدر إثبات ومسؤول بيانات.

## 5. هدف السنة الأولى
الهدف الاستراتيجي هو **تسجيل 100,000 مسوق مستقل خلال السنة الأولى**. لا يعني ذلك 100 ألف مسوق نشط أو عامل أو صاحب صفقة. يجب الإبلاغ منفصلاً عن التسجيل والتحقق، والنشاط خلال 30/90 يوماً، والفرص المؤهلة، والصفقات المكتملة، والدخل المدفوع، والوظائف المباشرة وغير المباشرة.

بعد اليوم 180، يكون التوسع حتى نهاية السنة الأولى بناءً على معدل التحويل وتكلفة اكتساب المشاركين والطلبات والقدرة على الدعم.

## 6. المخاطر
تأخر الموافقات أو تعاقد البنك والمصدر المرخص، ضعف جودة الطلبات، عدم تطابق السعر أو الكمية أو المواصفات، ازدواج إسناد العملاء، تأخر التحصيل، غموض العمولة، نقص السيولة، وتضخم التسجيل دون نشاط أو دخل. تراجع المخاطر شهرياً ويعدل النطاق عند الحاجة.

## 7. قرار اليوم 180
يصدر تقرير يوضح ما تحقق وما لم يتحقق، والصادرات الإضافية المنسوبة للمبادرة، وتكلفة كل صفقة وشحنة، ومستحقات المسوقين، وإيرادات المنصة، والشكاوى والامتثال. وبناء عليه تقرر الجهة المشرفة الاستمرار أو التعديل أو التوسع.
