## قواعد قراءة الوثائق
- الهدف الاستراتيجي: تسجيل 100,000 مسوق مستقل في السنة الأولى؛ التسجيل لا يعني النشاط أو تحقيق الدخل.
- العمولة المقترحة: 0.6% إجمالاً؛ 0.5% للمسوق و0.1% للمنصة، وتخضع للاعتماد القانوني والتعاقدي والتنظيمي.
- 180 يوماً مدة تجربة تشغيلية أولية وليست وعداً بإكمال التوسع الوطني.
- سقف 300,000 دولار هو مكافئ تخطيطي لتكاليف التجربة، ويطلب التعاقد والصرف بالجنيه المصري وفق آلية سعر صرف ودفعات منصوص عليها بالعقد.
- المنح الدولية ليست إيراداً مستحقاً لشركة التنفيذ، ولا تُعد مضمونة أو قابلة للتحويل إلى الخزانة العامة إلا وفق شروط المانح والاتفاقية.
- النموذج الأولي الحالي ليس منصة تشغيلية أو خدمة مالية/تصديرية مفعلة.
