# Wakeel Export — Project Documentation
## دليل وثائق المبادرة

هذا هو الفهرس الرئيسي لوثائق Wakeel. تاريخ قطع التحقق: **19 نوفمبر 2026**. المبادرة مقترح مستقل قيد الدراسة؛ لا يوجد حالياً تشغيل أو تعاقد أو طلب تمويل أو تقديم منح.

> **الحالة:** مقترح ونموذج أولي. لا توجد صفقات أو آثار أو منح محققة مثبتة. الأرقام المستقبلية أهداف أو افتراضات أو سيناريوهات ما لم تُعرّف كبيانات تاريخية رسمية.

## قواعد قراءة الوثائق
1. الحقائق: بيانات تاريخية رسمية مع المصدر والسنة والتعريف.
2. الافتراضات: مدخلات تخطيطية وليست بيانات سوق مثبتة.
3. التوقعات: نتائج محتملة مشروطة وليست ضمانات.
4. الأهداف: ما تسعى المبادرة إليه، لا ما تحقق.
5. هدف 100,000 هو تسجيل مسوقين في السنة الأولى، وليس 100,000 وظيفة أو مسوق نشط.
6. الزيادة المستهدفة 15% سيناريو طموح للصادرات غير البترولية الوطنية، وليست توقعاً رسمياً أو صادرات منسوبة تلقائياً إلى Wakeel.
7. عمولة 0.5% للمسوق و0.1% للمنصة مقترح يخضع للموافقات.
8. لا تعد المنح تمويلاً مؤكداً إلا بعد اتفاقية نافذة وصرف فعلي.
9. لا تعلن الوظائف أو الدخل أو خفض الانبعاثات أو الأثر الثقافي إلا بعد القياس.
10. أعد التحقق من الدعوات قبل التقديم.
