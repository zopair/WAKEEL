# نموذج التشغيل والأدوار | Operating Model

## 1. الغرض
Wakeel Export مبادرة مقترحة لربط المصانع المصرية المؤهلة بالطلب الدولي من خلال مسوقين مستقلين، مع إبقاء التنفيذ القانوني للتصدير لدى شركة أو جهة تصدير مرخصة، والتسويات لدى بنك أو مؤسسة مالية مخولة. المبادرة لا تمنح المسوق صفة المصدر القانوني أو الوسيط المالي أو الوكيل الجمركي.

## 2. الأطراف ومسؤولياتها
| الطرف | المسؤولية الأساسية | الحدود |
|---|---|---|
| المصنع/المورد | صحة بيانات المنتج والجودة والطاقة الإنتاجية والسعر والجاهزية والمستندات | لا يفوض غير المرخص بإصدار مستندات التصدير |
| المسوق المستقل | التعريف بالمنتجات، توليد العملاء المحتملين، متابعة الفرص وتوثيق مصدر العميل | لا يوقع مستندات التصدير بصفة المصدر ولا يحصّل قيمة البضائع |
| المنصة | إدارة بيانات الفرص والمطابقة والإسناد والتتبع والحوكمة والعمولات والتقارير | لا تمارس نشاطاً منظماً يتطلب ترخيصاً دون الحصول عليه |
| شركة التصدير المرخصة | التعاقد التصديري والفواتير والمستندات والامتثال والتخليص والشحن والتحصيل ضمن اختصاصها | لا تنقل مسؤولياتها القانونية إلى المسوق |
| البنك/مقدم الخدمة المالية | استقبال التحويلات والتسويات وفق القواعد والموافقات | لا ينفذ تسوية خارج التفويض والقواعد المصرفية |
| مقدم الخدمات اللوجستية | النقل والتجميع والتخزين والتأمين والتخليص بحسب الترخيص والعقد | يحافظ على استقلال الملفات القانونية للمصدرين |
| الجهة الحكومية المشرفة | تحديد الإطار التنظيمي والتنسيق والرقابة ضمن الاختصاص | المقترح لا يمثل موافقة نهائية |

## 3. دورة الصفقة
1. اعتماد المصنع والمنتج والتحقق من المواصفات والوثائق.
2. رصد طلب مشتري دولي أو فرصة توريد أو طلب عرض سعر.
3. تسجيل الفرصة ومصدرها وتاريخها وصاحب الإحالة.
4. مطابقة الطلب مع المنتج والقدرة الإنتاجية والاشتراطات والوجهة.
5. إحالة الفرصة إلى المصنع وشركة التصدير المرخصة.
6. التفاوض وإصدار العرض والعقد/أمر الشراء من الأطراف المخولة.
7. تنفيذ التصدير بواسطة المصدر القانوني والجهات المرخصة.
8. تأكيد الشحن والتحصيل والتسوية البنكية.
9. احتساب مستحق المسوق وحصة المنصة بعد تحقق شروط الاستحقاق.
10. إغلاق الصفقة وتسجيل مؤشرات الأثر والصادرات الإضافية.

## 4. استخبارات الطلب العالمي — Global Demand Intelligence
ترصد المنظومة طلبات الشراء والمناقصات وطلبات عروض الأسعار والاحتياجات المتكررة من مصادر تجارية مرخصة أو متاحة قانونياً. يجب تسجيل المصدر وتاريخ الرصد وشروط الاستخدام وموثوقية الطلب. الطلبات المتكررة غير المغطاة محلياً تتحول إلى إشارات لفجوات العرض وملفات فرص صناعية تتضمن:
- المنتج والمواصفات والكمية والوجهة والجدول الزمني.
- تكرار الطلب والحد الأدنى للكميات والأسعار المرجعية عند توفرها.
- فجوة القدرة الإنتاجية أو المواصفات أو الاعتماد.
- فرص تطوير المنتج أو الاستثمار أو نقل التكنولوجيا.
- المخاطر والاشتراطات البيئية والتجارية.

لا يوصف أي طلب بأنه طلب شراء مؤكد قبل التحقق من هوية المشتري وجديته وشروطه.

## 5. ضوابط الاستحقاق والتتبع
- إسناد الفرصة للمسوق وفق قواعد معلنة تمنع ازدواج الإسناد.
- سجل تدقيق لتاريخ الإحالة والتواصل والتفاوض والصفقة والتحصيل.
- لا تستحق عمولة على تسجيل حساب أو استفسار غير مؤهل أو صفقة لم تنفذ.
- نقطة الاستحقاق وقاعدة الاحتساب والخصومات والإلغاءات والنزاعات تحدد تعاقدياً.
- حماية بيانات المشترين والمصانع والمسوقين وعدم استخدامها خارج الغرض المعلن دون سند قانوني.

## 6. الوضع القانوني
هذا نموذج مقترح يتطلب مراجعة قانونية مصرية متخصصة وتحديد التراخيص والأدوار الضريبية والتعاقدية والمصرفية والجمركية وموافقات الجهات المختصة. لا تنشئ الوثيقة حقاً في ممارسة نشاط مرخص ولا تمثل اعتماداً حكومياً.
