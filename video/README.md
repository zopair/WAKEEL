# WAKEEL silent walkthrough

The delivery includes a separate 32-second, 1280×720, 12 fps H.264 MP4 walkthrough with no voice-over or soundtrack. It visually demonstrates the concept, demand discovery, supplier matching, deal workflow, consolidated shipment and illustrative commission model.

The MP4 is supplied as a conversation attachment because the repository integration accepts UTF-8 text files only and does not support binary media uploads. The video is not a live screen recording and does not depict real transactions.

## Render stack
- Python 3 + Pillow (HPND license) for deterministic frame composition.
- FFmpeg (LGPL/GPL build configuration applies to the installed binary) for H.264 MP4 encoding.
- No paid video-generation service, account, API key, watermark or external asset is used.

All visuals and values are illustrative. The video is silent and does not claim the platform is operational.
